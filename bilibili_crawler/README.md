# Bilibili 直播间实时数据抓取工具（终极版）

一款功能全面、稳定性强的 B 站直播间实时数据抓取工具，支持弹幕、礼物、大航海、互动行为等全维度数据采集，内置权重系统、登录防降级、昵称修复等核心特性，适用于数据分析、直播间监控、用户行为研究等场景。

## 📋 功能清单

| 核心功能 | 详细说明 |
| :--- | :--- |
| **全量数据采集** | 覆盖弹幕、付费礼物、免费礼物、大航海开通、进场互动、关注、分享、点赞等行为 |
| **登录防降级机制** | 支持 SESSDATA 登录，避免匿名模式下 UID 隐藏、昵称打码、数据限制等问题 |
| **用户权重系统** | 基于用户消费电池数自动累计权重，快速识别高价值用户 |
| **大航海精准适配** | 识别舰长/提督/总督开通、特殊舰队礼物（如干杯之旅），高亮日志提醒 |
| **昵称自动修复** | 通过 B 站 API 还原打码昵称（*** 替换），保证数据准确性 |
| **稳定连接保障** | 30秒心跳包维持连接，自动处理 zlib 压缩数据，断连友好提示 |
| **详细日志输出** | 按行为类型分级日志（普通/成功/重要），包含用户名、UID、权重等关键信息 |
| **跨平台兼容** | 支持 Windows/macOS/Linux 系统，Python 3.8+ 环境通用 |

## 🚀 快速开始

### 1. 环境准备

#### 1.1 安装 Python
确保本地安装 Python 3.8 及以上版本，下载地址：[https://www.python.org/downloads/](https://www.python.org/downloads/)

#### 1.2 安装依赖包
```bash
pip install requests websocket-client loguru
```

- `requests`：用于获取直播间信息、用户昵称修复、登录验证；
- `websocket-client`：建立 WebSocket 连接，接收实时弹幕数据；
- `loguru`：日志输出格式化，支持分级显示。

### 2. 获取 SESSDATA（可选但强烈推荐）

#### 2.1 作用
- 避免匿名模式限制（如 UID 显示为 0、昵称打码、部分数据无法获取）；
- 提升爬虫稳定性，降低被 B 站风控限制的概率。

#### 2.2 获取步骤
1. 用浏览器（Chrome/Edge/Firefox）打开 [https://www.bilibili.com/](https://www.bilibili.com/) 并登录账号；
2. 按 F12 打开开发者工具，切换到“Application（应用程序）”标签；
3. 左侧导航栏找到“Cookies”→ 选中 `https://www.bilibili.com`；
4. 右侧列表中找到“SESSDATA”，复制其“Value”值（无需解码，直接复制完整字符串）。

#### 2.3 注意事项
- SESSDATA 是个人账号登录凭证，**请勿泄露给他人**，泄露可能导致账号被盗风险；
- 有效期约 6-12 个月，若出现登录失败提示，需重新获取；
- 更换设备、修改密码或手动退出登录后，原 SESSDATA 会失效。

### 3. 运行脚本

#### 3.1 基础运行
```bash
# 克隆或下载脚本文件后，进入脚本所在目录
python crawler.py
```

#### 3.2 交互流程
1. 脚本启动后，会提示输入 SESSDATA：
   - 粘贴已获取的 SESSDATA 后回车（推荐）；
   - 直接回车则以游客模式运行（功能受限）；
2. 输入目标直播间的“短房间号”（如直播间 URL 为“https://live.bilibili.com/123456”，则输入“123456”）；
3. 脚本自动获取直播间真实房号、连接配置，成功后开始实时抓取数据。

## 📊 日志说明

### 日志格式

```plaintext
[时间] | [行为类型] 用户名: 行为详情 [权重X] [UID:xxx]
```

### 行为类型与日志级别

| 行为类型 | 日志级别 | 示例输出（时间） | 示例输出（内容） |
| :--- | :--- | :--- | :--- |
| 弹幕 | 普通（白色） | 14:35:22 | `[弹幕] 张三: 主播加油！[权重1] [UID:12345678]` |
| 免费礼物 | 普通（白色） | 14:36:05 | `[礼物] 李四: 投喂 1 个 小心心 (免费礼物) [权重1] [UID:87654321]` |
| 付费礼物 | 成功（绿色） | 14:37:10 | `[礼物] 王五: 投喂 5 个 你真好看 (共 50 电池) [权重51] [UID:11223344]` |
| 大航海开通 | 重要（黄色） | 14:38:25 | `★★ [大航海] 恭喜 赵六 购买了 1 个 舰长一号！(价值 1980 电池) [权重1981] [UID:55667788] ★★` |
| 进场/关注/分享 | 普通（白色） | 14:39:15 | `[互动] 孙七 关注了主播 [权重1] [UID:99887766]` |
| 点赞 | 普通（白色） | 14:40:08 | `[点赞] 周八 为主播点赞了 [权重1] [UID:22334455]` |

### 权重计算规则

- **初始权重**：所有用户默认权重为 1；
- **权重增长**：仅付费行为累计权重（1 电池 = 1 权重）；
  - 🔴 **付费礼物**：按总电池数增加权重（如 50 电池礼物 → 权重 +50）；
  - 🔴 **大航海开通**：按价格换算电池数增加权重（如舰长 198 元 → 1980 电池 → 权重+1980）；
- 免费礼物、弹幕、互动、点赞等行为不增加权重。

## 🐞 常见问题排查

1. **连接失败/日志无输出**
   - 检查网络环境：确保网络通畅，无防火墙拦截 WebSocket 连接（端口 443）；
   - 验证 SESSDATA：若已输入 SESSDATA，尝试重新获取后再次输入；
   - 确认房间状态：目标直播间需处于「开播中」状态，未开播房间无数据输出。

2. **昵称显示为 `***`**
   - 未输入 SESSDATA：游客模式下 B 站会隐藏部分用户昵称，建议输入 SESSDATA 登录；
   - SESSDATA 失效：重新获取 SESSDATA 并输入，或检查账号是否已退出登录。

3. **权重计算异常**
   - 免费礼物不增加权重属于正常逻辑，仅付费礼物/大航海会累计权重；
   - 若付费行为未增加权重，检查 `update_weight` 函数中 `add_score` 参数是否正确传递。

4. **脚本崩溃/报错**
   - 检查 Python 版本：确保为 3.8+，低版本可能存在语法兼容问题；
   - 重新安装依赖：执行 `pip install --upgrade requests websocket-client loguru` 更新依赖包；
   - 查看错误日志：脚本会输出详细报错信息，根据报错提示定位问题（如网络超时、API 响应异常等）。
